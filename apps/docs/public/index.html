Android Gateway

Register a device with a project API key, then authenticate device calls with X-Device-Token.

  • POST /v1/device/register
  • POST /v1/device/heartbeat
  • GET /v1/device/outbox
  • POST /v1/device/send
  • POST /v1/device/inbox
